# EPC13 Web — v1 (Módulo Aderência)

Primeira versão online do módulo de Aderência Semanal, conectada ao Supabase.

## O que já funciona nesta versão
- Criar semanas
- Adicionar itens numa semana
- Marcar status de cada dia (clique no dia pra alternar: — → ✔ → ⚠ → ✘ → ★ → —, sem programação também no ciclo)
- Adicionar/remover TAGs por item
- Tudo salva direto no banco (Supabase) — qualquer pessoa que abrir o link vê os mesmos dados, em tempo real ao recarregar a página

## O que ainda falta (próximas etapas)
- Situação por TAG (comparação com semanas anteriores)
- Devolutiva
- Emissão de PT
- Relatórios e histórico
- Módulo de Drafts (arquivos)
- Edição em tempo real sem precisar recarregar a página
- Login/permissões
